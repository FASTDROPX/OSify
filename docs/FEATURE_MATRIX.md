# Feature matrix — OSify 0.4.1

Актуальная матрица заменяет отчёт 0.1.0: [исторический документ](FEATURE_MATRIX_0.1.0.md). Сборка, тест протокола на хосте и испытание на Android — разные виды доказательств.

| Возможность | Реализация и границы проверки |
|---|---|
| Центральный Launcher, пять вкладок | Реализовано; native-рендеры и UI-тесты навигации. Запуск находится здесь, управление файлами — в «Загрузках» |
| Каталог / загрузки / импорт | Работают существующие проверка SHA, возобновление, SAF и фоновые задачи; прежние транспортные тесты сохранены. Каталог по умолчанию x64 для ISO QEMU |
| Каталог и Launcher по референсу | Реальные изображения в компактных плитках, готовность/ошибки из настоящих данных, основные действия и меню VM. UI-рендеры и функциональные тесты; подробности в UI_0.4.1.md |
| Ubuntu ISO | Официальный Desktop 24.04.5.1 LTS x64, SHA-256 и размер сверены с upstream. Полный ISO и запуск Ubuntu на Android в этой сессии не испытывались |
| Windows ISO | Официальная Windows 11 Evaluation скачивается по инициативе пользователя; произвольный лицензированный ISO импортируется. Windows 10 — официальный источник/импорт. Образы в APK не включены |
| Конфигурация VM | x64, 256–4096 MiB RAM, до половины физической памяти; 1–4 CPU, sparse QCOW2 2–128 GiB, BIOS/UEFI + TPM, ISO/диск. Параметры входят в настоящую команду QEMU |
| QEMU | Внешний Termux, TCG. Продукционные команды проверены с реальным QEMU хоста. Установка/запуск через Android Termux на Realme не подтверждены |
| Linux x64 из ISO | На хосте Alpine загружен до root shell, получен настоящий framebuffer и вывод uname. Это не Android-проверка и не поддержка произвольных дистрибутивов |
| Linux без эмуляции | Внешний Alpine PRoot, ядро Android. Фиксированный протокол Termux; итоговое испытание на телефоне остаётся открытым |
| Windows x64 | Реальный QEMU хоста показал Windows 11 Setup. Полная установка, рабочий стол, Tiny 11 пользователя и производительность ARM-телефона не проверены |
| BIOS/UEFI + TPM | Генерация настоящих параметров EDK2/swtpm; результат командного integration-теста находится в runtime evidence. Не обходят требования Windows |
| Экран гостя | Собственный RFB 3.8 клиент, парольный loopback VNC; реальный framebuffer QEMU проверен. Android-native контейнер собирается, физический ввод/IME на Realme не проверен |
| Ввод | Касание, drag, ПКМ, двухпальцевая прокрутка, zoom/pan, Esc/Tab/CtrlAltDel, аппаратные клавиши и IME реализованы; подробные OEM/раскладки требуют устройства |
| Пауза / продолжение / остановка | Настоящий QMP по приватному Unix-сокету. Pause/resume/quit проверяются на хосте; ACPI shutdown зависит от гостя |
| Состояния / восстановление | Callback с токеном, SQL защита от запоздалых результатов, сброс ожидания, неизвестный статус после перезапуска. Отправка команды не считается успешной загрузкой ОС |
| Данные | Миграция Room 1 → 2 сохраняет старые данные. ISO в Termux копируется один раз с SHA. Запись VM и внешние файлы удаляются отдельно |
| Анимации / FPS | Сбор потоков изолирован по карточкам; вход страницы использует готовые размеры и слой прозрачности. Высокая частота запрашивается, но 120 FPS на телефоне не измерены. Реальные FrameMetrics доступны в диагностике |
| Темы / AMOLED | Сохранены плавные роли цвета, системная/светлая/тёмная/обои, AMOLED и full/reduced/off motion; native-визуальные тесты |
| Настройки / диагностика | EN/RU, DataStore, реальные состояния/журналы и FrameMetrics. Технические ошибки движка могут быть на английском |
| Лицензии / подпись | QEMU/Termux/swtpm/firmware не включены в APK; внешние официальные пакеты. Компактный APK подписывается прежним debug-сертификатом v1/v2/v3, отдельно проверяется API 36 |
| Не реализовано | KVM/аппаратное 3D/звук/SPICE/общие папки/USB passthrough/сохранение живой RAM/импорт готовых QCOW2 как системного диска/автоматическое определение загрузочности ISO |

Дальнейшая проверка: Android 16 Realme → Termux → QEMU, установка/перезапуски Windows, фоновые ограничения/OEM/нагрев, аппаратный FPS, IME/размеры текста/TalkBack. Успешная сборка не закрывает эти пункты.
