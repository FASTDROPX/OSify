# OSify 0.4.4 — Material управление гостевой ОС

3 ноября 2026. Android 8+ / ARM64 и x86_64. Версия 0.4.4, code 11, target API 36.

## Новое управление

- Экран гостя переведён на Compose Material 3 с выбранной темой OSify. Наверху имя машины, fullscreen и меню. Снизу компактная панель с понятными подписями и полноценными зонами касания от 48 dp. В портретном режиме подписи находятся под иконками, в альбомном управление собирается в одну строку. Подписи проверяются на переполнение.
- «Текст» открывает редактор с обычной Android-клавиатурой, выделением и исправлением текста. «Из буфера» читает буфер телефона только по нажатию. «Копировать» сохраняет текст в буфер телефона. «Вставить в ОС» копирует введённое в буфер телефона и отправляет гостю как клавиши. Лимит редактора — 8192 символа, перенос строки отправляет Enter. Гостевой буфер автоматически не синхронизируется; раскладка и поддержка символов определяются самой ОС.
- «Клавиатура» открывает клавиатуру для прямого ввода в гостя. Добавлена обработка физических клавиш: стрелки, Home/End/Page Up/Page Down, Insert/Delete, Win, Ctrl/Alt/Shift, F1–F12. При смене фокуса/закрытии панели или уходе из приложения зажатые кнопки и клавиши отпускаются.
- «Мышь» включает видимый курсор и режим тачпада: движение пальцем перемещает курсор относительно его текущего положения, касание кликает. Удержание даёт ПКМ, два пальца прокручивают. Дополнительно доступны ЛКМ/ПКМ, стрелки прокрутки и «Тянуть» для удержания левой кнопки. Отмена жеста, второй палец или выключение мыши отпускают кнопку. Режим запоминается.
- Щипок увеличивает изображение до 5×. В режиме касаний два пальца двигают увеличенный экран, в режиме мыши курсор автоматически удерживается в видимой области. В меню доступны вписать, увеличить/уменьшить, поворот, переподключение и инструкция.
- Fullscreen скрывает верхнюю/нижнюю панели и системные строки. Маленькая кнопка в углу или Android «Назад» возвращает управление. Системные строки временно вызываются свайпом от края. Возврат в Launcher скрывает экран, сохраняя работающую ОС.
- Исправлена передача текста RFB: один упорядоченный пакет на порцию текста, CRLF не превращается в два Enter, Unicode не рвётся по границе порции. Ввод не отправляется до завершения аутентификации; при отключении сначала дописываются события отпускания клавиш/кнопок.

Размер APK: 20,777,518 байт. SHA-256: `566d158655ba51765e527ad564cc75b9c37bda60c992910e8c8b1802e2e1fdc1`.

Сертификат SHA-256: `5a430f433d75d0d54a41647ef97bc13ee682dbcee2ee0693876e6e76071b32d9` — тот же локальный Android Debug ключ, что у выданных здесь 0.4.2/0.4.3. APK обновляет их без удаления данных. Ключ оригинального 0.4.1 в исходном архиве отсутствовал; для обновления поверх оригинального APK нужен его ключ. Удаление приложения стирает его данные и виртуальные диски — сохраните нужное заранее.

Исходное приветствие и каталог сохранены. Движок и прошивки из 0.4.3 не заменялись. В исходниках остаются соответствующие исходники QEMU/Limbo и зависимостей, оригиналы изображений и лицензии.

## Практические ограничения

Проверка выполнена в Android-эмуляторе на Alpine. Физический ARM64-телефон, физические USB/Bluetooth устройства, графический рабочий стол Windows и двусторонний буфер гостя не проверялись. Эмуляция программная, без KVM; скорость тяжёлых Windows на телефоне не обещается. XP/7/10/Tiny требуют собственного ISO; обычному Windows 11 может не хватать TPM 2.0. Нативные библиотеки QEMU имеют 4 KB ELF; включён Android pageSizeCompat, но 16 KB устройство не тестировалось. Новый JNI-адаптер OSify выровнен на 16 KB.

Реализация использует [Material ModalBottomSheet](https://developer.android.com/develop/ui/compose/components/bottom-sheets) и [Android immersive mode](https://developer.android.com/develop/ui/views/layout/immersive). Инструкция сборки и управления: README.md.
