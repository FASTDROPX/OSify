# OSify — Every OS. One App.

Android-приложение **0.4.5**: каталог из **36 ОС и редакций**, загрузки с SHA-256 и встроенный PC-эмулятор QEMU. **Termux и root не нужны.** Поддерживаются телефоны ARM64 и устройства x86_64; гостевые системы — семейство x86/x64.

## Экран ОС и управление в 0.4.5

Экран гостя использует Material 3 и выбранную тему OSify. Основные действия находятся снизу; в альбомной ориентации панель вертикальная справа. Панель доступна и в fullscreen.

- **Клавиатура** открывает обычную Android-клавиатуру для прямого ввода в ОС. Физические клавиатуры также передают клавиши гостю.
- **Текст** открывает редактор с привычной клавиатурой, выделением и исправлением текста. «Из буфера» читает буфер телефона только после нажатия. «Копировать» сохраняет введённое в буфер телефона. **«Вставить в ОС»** копирует текст в буфер телефона и передаёт его гостю как нажатия клавиш. До 8192 символов за раз; перенос строки отправляет Enter. Раскладка и поддержка символов зависят от гостевой ОС. Это не автоматическая двусторонняя синхронизация буфера гостя.
- **Мышь** включает видимый указатель и тачпад: палец двигает курсор, касание кликает, удержание даёт ПКМ, два пальца прокручивают. Доступны ЛКМ/ПКМ, колесо и «Тянуть» для перетаскивания. Режим запоминается. Отмена жеста, переход к двум пальцам или выключение режима отпускают кнопку.
- **Клавиши** содержит Ctrl/Alt/Shift/Win, стрелки, Esc/Tab/Enter, Home/End/PgUp/PgDn, Ins/Del, F1–F12 и Ctrl+Alt+Del. Модификаторы отпускаются при закрытии панели или уходе из приложения.
- Щипок увеличивает изображение до 5×. В режиме касаний два пальца двигают увеличенное изображение. В меню: вписать, увеличить/уменьшить, повернуть, переподключить экран и инструкция.
- **На весь экран** скрывает заголовок, статус и системную навигацию. Управление остаётся доступным. Кнопка в углу возвращает заголовок. Android «Назад» открывает выбор: скрыть экран, перейти в настоящий Android PiP или остановить машину. Системные строки временно вызываются свайпом от края.

- **PiP** оставляет живой экран ОС в плавающем окне Android; раскрытие возвращает управление. Закрытие окна скрывает экран, машина продолжает работу в службе. Доступность PiP зависит от устройства и системного разрешения приложения.
- **Логи машины · TXT** в меню экрана и «Журнал движка» в Launcher: обновить, сохранить через Android Documents или отправить файл через Android Share. Сохраняются события OSify, stdout/stderr QEMU и serial гостя; текущая и предыдущая сессии. Экспорт ограничивает каждый раздел последним 1 MiB, известные секреты VNC/операции скрываются. Полный журнал гостя автоматически с VGA не считывается. Кнопка «Собрать журнал Linux» готовит команду в редакторе; выполнение требует консоль гостя и нажатие Enter.
- **Изменить конфигурацию** в меню остановленной машины: название, RAM и ядра ползунками, BIOS/UEFI. Применяется при следующем запуске, без удаления диска. Образ и ёмкость существующего диска сохраняются. Менять прошивку установленной ОС следует с учётом её загрузчика.
- Каталог закрывается с обратной кривой открытия и той же длительностью. Описание сохраняет шрифт, ширину и переносы каждой конечной раскладки; во время перехода меняется прозрачность.

[Изменения и проверка 0.4.5](docs/GUEST_CONSOLE_0.4.5.md). Снимки получены на настоящем Alpine в Android-эмуляторе; физические USB/Bluetooth устройства и Windows в этой проверке не использовались.

## Что изменилось

- Каталог приезжает снизу, карточки дополнительно проявляются слева. Фильтры анимируют выход и возвращение карточек.
- Кнопка на плитке сразу начинает загрузку и заполняется по настоящему прогрессу. В раскрытой карточке счётчик MB/GB появляется внутри кнопки; состояния, текст и иконки переходят плавно.
- Раскрытие и закрытие используют измеренное положение и непрерывный размер одной кнопки. Подзаголовок скрывается на время изменения ширины.
- Настоящие логотипы и обложки найдены в интернете. Логотипы прозрачные, с одинаковой видимой высотой 40 dp в слоте 48 dp. Источники и оригиналы включены.
- Windows XP, 7, 10, 11, Tiny10 и Tiny11. Tiny11 отмечена золотой рамкой и подписью «Лучший выбор» по требованию владельца приложения. Для XP/7/10/Tiny используются собственные ISO; установочные образы Windows не распространяются с APK.
- В каталоге один Alpine virt ISO. Большой каталог использует открытый JSON API Quickget и встроенный снимок для работы без сети.
- Launcher запускает QEMU в отдельном процессе Android, показывает настоящий экран гостя через RFB, управляет паузой и остановкой через закрытый QMP-сокет. Обложки машин квадратные.
- Исходное приветствие восстановлено **байт в байт** из архива 0.4.1. Повторный просмотр: Настройки → Повторить знакомство. Его исходный текст сохранён, включая историческое упоминание Termux; актуальная инструкция запуска приведена ниже.

## Запуск ОС

1. Скачайте ISO из каталога или импортируйте свой ISO/IMG/QCOW2 в «Загрузках».
2. Откройте Launcher → +, выберите образ, память, ядра, диск и BIOS/UEFI.
3. Нажмите «Запустить». Кнопка за 500 мс заполняется тёмным цветом, play превращается в квадрат, появляется «Остановить». После готовности QEMU открывается экран гостя.
4. Установите ОС на виртуальный диск. Для последующих запусков выберите Параметры → Установленный диск.
5. «Остановить» завершает процесс машины. Для обычного завершения самой гостевой ОС используйте её меню питания или «Завершить работу гостя» в меню машины. Остановка машины может потерять несохранённые в госте данные.

Одновременно работает одна машина. Диски находятся в закрытом каталоге OSify и удаляются вместе с приложением. Удаление машины удаляет её виртуальный диск, исходный образ остаётся в «Загрузках». Общие папки телефона гостю не предоставляются.

## Проверки и ограничения

Проверен настоящий Alpine Linux 3.24.3 x64 в Android API 35: BIOS и UEFI до экрана входа, ввод `root`/`uname -a`, RFB-экран, QMP pause/resume/quit и повторный запуск. Проверки фиксируются в [отчёте 0.4.3](docs/UI_RUNTIME_0.4.3.md). Прежние документы в docs относятся к своим версиям и не описывают текущий движок.

Это программная эмуляция, KVM не используется. Скорость тяжёлых Windows на ARM не обещается. Совместимость каждой из 36 ОС и полная установка Windows не проверены. TPM 2.0 не эмулируется: обычный Windows 11 может отказать в установке из-за требований оборудования. Tiny11 — отдельная сборка NTDEV и не является Microsoft Windows ISO, включённым в приложение.

Нативные библиотеки Limbo/QEMU — 4 KB ELF. Для 16 KB Android включён штатный pageSizeCompat, но 16 KB устройство не проверялось. Новый JNI-адаптер OSify выровнен на 16 KB. Полная поддержка 16 KB потребует пересборки зависимостей. Устройства ARM32 не поддерживаются этим APK.

## Сборка

JDK 21, Android SDK 36, Build Tools 36.0.0. Gradle 8.13 / AGP 8.13.2 / Kotlin 2.2.21. Нативные библиотеки уже включены, поэтому NDK для обычной сборки не нужен.

```powershell
.\gradlew.bat :core:test :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

Пересборка JNI-адаптера: `tools/build-native-bridge.ps1 -NdkRoot <NDK-r28.2>`. Исходник: `app/src/main/cpp/osify_vm.c`. Полные исходники и патчи стороннего движка находятся в `third_party/native-sources/`; инструкции Limbo включены в исходный ZIP. Для инструментального NativeBootDeviceTest сначала положите официальный Alpine virt ISO в `/sdcard/Android/data/dev.osify.app/files/boot-test.iso`.

Приложение не содержит аккаунтов, рекламы, аналитики и токенов приватного GitHub. Все загрузки — публичные HTTPS-источники. Старые Termux-адаптеры сохранены в исходниках для истории, основной Launcher их не использует.
