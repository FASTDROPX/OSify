# Проверки OSify 0.4.0 — 3 ноября 2026

Актуальный отчёт относится к Launcher/QEMU и оптимизации подписок UI. [Испытания 0.1.0](TEST_RESULTS_0.1.0.md) сохранены отдельно и не считаются проверкой нового APK на устройстве.

## Автоматические проверки

В финальном прогоне 46 тестов: 45 пройдено, один условный тест существующего VNC-процесса пропущен после завершения тестовых VM. Его реальные Linux/Windows прогоны сохранены отдельно. Точный итог, логи и XML — `evidence/runtime-0.4.0/RESULTS.json`.

Новые проверки:

- Loopback-мост отдаёт точные байты выбранного ISO; произвольный путь получает 404.
- Строгие параметры/экранирование команды QEMU.
- Настоящие производственные bash-команды создают QEMU BIOS и UEFI + swtpm, копируют Alpine ISO через производственный мост с SHA, выполняют QMP pause/resume/quit и запускают тот же диск без ISO. Это хостовые процессы, не подмена движка.
- Room 1 → 2 открывает и валидирует новую схему с сохранённым старым профилем; поздний callback не переписывает более новый запрос.
- Android-запрос подготовки использует фактический RUN_COMMAND контракт Termux и остаётся REQUESTED до callback. Robolectric не исполняет этот Android Intent во внешнем приложении.
- UI-тесты пяти вкладок, создания VM, русских подписей, неподвижной шапки, промежуточных анимационных кадров, тем и больших шрифтов. Все визуальные кадры получены из настоящих Compose-компонентов native-рендером Robolectric API 34; это не скриншоты Realme.

## Ограничения

Тестовый Android-эмулятор в этой сессии не запустился из-за требования свободного диска. Полный путь Android 16 Realme → Termux → QEMU, Tiny 11 пользователя, экранная клавиатура/жесты на физическом экране, фоновые ограничения OEM, 120 FPS, температура/потребление, установка Windows и сохранность VM после аварий ещё требуют устройства. QEMU хоста 10.0.13 отличается от проверенных метаданных пакета Termux 11.1.3.

Отрисовка оптимизирована по источникам обновлений: root не собирает RAM и все загрузки. Перемещение элементов использует готовые размеры. Эксперимент с чистым transform обрезал текст в промежуточных native-кадрах, поэтому отклонён. Запрос высокой частоты не равен измеренным 120 FPS; диагностика пишет настоящие FrameMetrics без выдуманного FPS.

Гостевые ISO, Termux и QEMU-пакеты не включаются в исходный ZIP или APK. Внешние VM после испытаний остановлены. Компактный APK подписывается тем же debug-ключом, схемы v1/v2/v3, отдельно проверяется установка подписи для API 36. Это ручная тестовая сборка, не выпуск Google Play.
