# OSify 0.3.2

Шапка с логотипом, OSify и кнопкой настроек вынесена из AnimatedPageColumn в отдельную неподвижную область. Прокрутка и анимация смены страниц происходят под шапкой. Остальные переходы и Navigation Reflow сохранены.

Полоса занятой памяти заменена на MemoryWaveProgress. Это нативная Canvas-дорожка с амплитудой 0,9 dp и толщиной 3 dp. Частота непрерывно зависит от интерполированного заполнения: 2 + 6 × заполнение циклов на полную ширину дорожки. Значение интерполируется за 1100 мс, фаза непрерывна и повторяется за 2600 мс. Поэтому частота и длина заполнения меняются плавно, без дискретного переключения. Незаполненный хвост прямой, линии под заполненной волной нет.

При reduced motion фаза неподвижна; при off остаётся статическая прямая полоса. При недоступных показателях памяти не запускается бесконечная анимация. Пользовательские данные по памяти поступают из прежнего DeviceProfiler, изменения чисел не моделируются таймером.

Проверки: Robolectric API 34, реальные кадры переходов и RAM 20/70/95%. В UI-тесте проверяется неизменность границ app-header в начале и середине переходов. Дополнительно сравнены пиксели шапки в 14 PNG переходов: различий нет. Визуально просмотрены малое и большое заполнение и кадры промежуточной интерполяции. Производительность на физическом Realme в этой среде не измерялась.

APK полный, компактный, подписан прежним сертификатом по v1/v2/v3. Отдельная проверка подписи выполняется для API 36. Запуск ISO в этом обновлении не добавлялся.

Итог: 36 тестов пройдено, 0 errors, 24 warnings. Логи и кадры находятся в `docs/evidence/ui-0.3.2`.
