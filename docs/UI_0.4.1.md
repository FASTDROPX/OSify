# Каталог и Launcher по референсу — 0.4.1

Реализованы в приложении, а не отдельным HTML-макетом.

## Каталог

Компактные горизонтальные плитки с изображением системы, знаком ОС, коротким описанием, архитектурой/форматом и одной кнопкой скачивания. Изображения входят в APK и не требуют сетевой подгрузки. Страница содержит рабочие поиск и сочетания фильтров Linux/Windows, минимальные/ISO. Источники, дата снимка и переключение архитектуры вынесены вниз в раскрываемый раздел.

Windows 11 — официальный Evaluation ISO внутри прежнего загрузчика. Пользовательский Tiny 11 импортируется в «Загрузках», не скачивается с непроверенного зеркала. Windows 10 остаётся ссылкой на Microsoft, что прямо указано на кнопке.

Добавлен Ubuntu Desktop 24.04.5.1 LTS x64. На 3 ноября 2026 проверены официальный SHA256SUMS и HEAD ISO: 6 250 332 160 байт; SHA-256 `4da4a0c9035da8e68a59a838674f403f0a54472c78a83b4fb7f78d03588f85a7`. Источник `releases.ubuntu.com` добавлен к HTTPS allowlist; произвольные зеркала и неподходящие редиректы не разрешаются. Ubuntu использует существующие проверку SHA, паузу и возобновление. ISO в среде целиком не скачивался, запуск Ubuntu на Android не проверен.

## Launcher

Вверху небольшая иллюстрированная карточка подготовки Termux. В «Моих системах» отображаются настоящие сохранённые конфигурации и их текущие состояния. Плитка содержит обложку, название, статус, RAM/архитектуру/прошивку и основное действие. У активной VM основная кнопка открывает экран; у приостановленной — продолжает её; у остановленной — запускает. Дополнительные команды и журнал находятся в меню «⋮». «Параметры» показывает ресурсы и позволяет выбрать ISO/установленный диск для следующего старта.

Отдельная среда Alpine/PRoot подписана как Linux в Termux и не выдаётся за установленный QEMU-гость. Её основная кнопка использует реальную установку/запуск при готовой интеграции; подробности открывают существующую панель движка. Количество «Моих систем» не включает неустановленную среду.

При выборе ISO редактор предлагает название и тип гостя по образу. Для Ubuntu предлагается диск 32 GiB, Windows — 64 GiB, Alpine — 8 GiB; это предел разреженного диска, а не сразу занятое место. Общие ограничения RAM/CPU и выполнение QEMU не изменены.

## Изображения и отрисовка

- Windows Bloom (Microsoft), обои Ubuntu из upstream, горная фотография Unsplash, знаки Ubuntu/Alpine из Simple Icons. Источники и права перечислены в `docs/artwork/CREDITS.txt`; лицензии/атрибуция также включены в assets APK и сведения о приложении.
- WebP уменьшены до 960 px. Это декоративные изображения, не скриншоты запущенного гостя.
- Декодирование выполняется в Dispatchers.IO. Кэш привязан к Resources с weak-ссылками на владельца и хранит три известных изображения; переходы повторно их не декодируют. Встроенные изображения не открывают дополнительные сетевые соединения.
- Сохранены неподвижная шапка и Navigation Flow с Launcher в центре.
- При увеличенном шрифте кнопки машины располагаются друг под другом, чтобы подписи не разрывались по буквам.

## Проверки

Native-рендеры реальных Compose-экранов в Robolectric API 34: каталог и Launcher по-русски, фильтр Linux/ISO, окно Ubuntu, тёмная/светлая темы с масштабом текста 1,35, промежуточные анимационные кадры. В preview Launcher используется явно тестовая конфигурация Tiny 11; её наличие не означает запуск Tiny 11.

Тесты проверяют навигацию, фильтры, доступность загрузки Ubuntu, выбор загрузки с диска и журнал из меню VM. Сохраняются транспортные, Room, lifecycle и security-тесты. Хостовые QEMU-тесты условные; не запускаются повторно в UI-обновлении и их прежние результаты не считаются проверкой Android. Физический Realme и FPS на нём недоступны.

Итоговые XML, логи и кадры — `docs/evidence/ui-0.4.1`.
