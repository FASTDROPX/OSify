# OSify 0.4.2 — понятный интерфейс и раскрытие каталога

Каталог использует отдельную нативную Compose-сцену `CatalogExperience`. Начальная геометрия берётся с выбранной карточки. Изображение расширяется до ширины области под неподвижной шапкой; заголовок, плашки и кнопка переходят в подробную страницу. Другие карточки уходят влево последовательно сверху вниз. Обратный переход возвращает в исходное место списка. Кнопка возврата закреплена над прокручиваемым содержимым, инерционная прокрутка перед возвратом останавливается.

Присланные Windows 11, Windows 10, Ubuntu и Alpine сохранены оригинальными файлами. `OsLogo` использует прозрачные маски/оптическое кадрирование для удаления полей, печатной шахматки и белого фона вокруг знака. Все видимые знаки в каталоге, Launcher и других экранах имеют общий прозрачный контейнер 48 dp и одинаковую видимую высоту знака 40 dp. Подложки под логотипами отсутствуют. Цветные круг Ubuntu и шестиугольник Alpine являются частями самих логотипов.

Компактная карточка имеет минимальную высоту 156 dp; при большом тексте растёт. Метаданные выровнены по низу вместе с действием, отступ от края одинаковый. Download Fill повторяет компонент 06 из предоставленного V11: асимметричные скругления, заполнение всей поверхности реальным прогрессом, плавная форма завершения и векторная иконка Check вместо символа галочки. Загрузка, пауза, продолжение, ошибка и готовность связаны с существующими Room/WorkManager.

Главная показывает понятные входы в каталог/Launcher и реальные счётчики. Библиотека использует обложки ОС и разделяет главное действие и меню файла. Launcher показывает подготовку среды и собственные машины. При отсутствии ISO вместо пустой формы предлагается сначала добавить образ. Настройки получили понятные группы с иконками и текущими значениями. Знакомство показывает системы вместо одних номеров.

Проверки включают JVM/Compose, lint, R8 и установленное приложение на Android API 35. Отдельный тест с управляемым Compose clock проверяет промежуточную геометрию, неподвижность шапки и возврат. Native-скриншоты получены с эмулятора. Конфигурации машин для проверки логотипов — явно тестовые, не загружаемые ОС; после теста удаляются. Проверки QEMU/Termux на телефоне и производительность гостевых ОС не входят в это обновление.

Приложение не публиковалось. Предоставляемый APK — оптимизированная сборка R8, подписанная локальным Android debug-сертификатом для ручного тестирования; исходники не содержат ключей. Это не прежний сертификат из чужой среды сборки. Для обновления существующего APK без удаления данных требуется совпадающий сертификат.
