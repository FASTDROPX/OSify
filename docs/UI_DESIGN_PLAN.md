# UI direction
Native Compose implementation using the supplied V11 and reference screenshot.
Palette: OSify blue #91C8FF; near-black #101418; slate #1A222A; off-white #E5EBF1; secondary #A6B4C1. Existing light and AMOLED themes remain.
Type: existing brand families retained; headings compact, readable body labels, no extra display fonts.
Layout: fixed OSify header → full-width expanding OS art → specifications → real Download Fill → import/supporting details. Card transforms from its measured screen bounds; surrounding rows leave left in sequence. Reverse animation returns to the original scroll position.
Overview: choose system, current machine/download activity, phone resources. Launcher: preparation, own systems, native Linux. Library: OS artwork, file progress, primary action, secondary menu. Settings: icon-led labelled groups and clear current values.
Keep one expressive feature: catalog expansion. Motion off/reduced remain usable. No fake downloads or guest state.
