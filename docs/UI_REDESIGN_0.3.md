# OSify 0.3.0 — реализация плана UI

## Исходные материалы и карта компонентов

Использован фактически предоставленный `M3_Expressive_Extras_V10.html` (в заголовке задания упоминается V11, но архив содержит V10). HTML изучен как спецификация геометрии и переходов, приложение остаётся нативным Kotlin/Compose.

| Компонент | Экран и назначение | Состояния и движение |
|---|---|---|
| Navigation Reflow / stageNav | Главная, каталог, загрузки | Активный раздел расширяется, соседние сжимаются, внешние углы асимметричны на крайних позициях; размеры и углы интерполируются |
| Page Morph Carousel / v6-slide | Четыре этапа знакомства | Центр 76% ширины, следующая форма 71% размера с поворотом 7°, переход формы/масштаба/позиции/прозрачности, кнопки и горизонтальные свайпы |
| Segmented | Этапы знакомства | Четыре сегмента, плавное заполнение, завершение зелёным |
| Download → Progress / v7-download | Действие в каталоге и реальные загрузки | Компактная кнопка расширяется до панели, заполняется целиком по байтам Room/WorkManager; пауза, повтор, проверка, готовность с появлением галочки |
| Wavy | Неопределённая проверка и длительные операции | Движется только активная волна, без линии под ней; остаток дорожки прямой |
| Primary Morphing Action | Подготовка среды Termux | Контур значка и радиус кнопки меняются по реальному состоянию запроса, открывается управление движком |
| Expandable Action | Ресурсы и расширенный профиль | Детали памяти и телефона открываются по запросу; недоступные параметры QEMU не изображаются работающими |
| Secondary Tonal / выбор | Настройки | Компактные строки, тематические страницы, диалоги одиночного выбора; сохранение в DataStore |

Общие токены цвета и типографики находятся в Theme.kt, токены движения и новые компоненты — Expressive.kt. Цвета по умолчанию основаны на голубом значке OSify. Динамическая палитра включается явно; старое автоматическое включение цветов обоев не переносится на новую настройку.

## Экраны

- Главная: фирменная надпись, настройки в шапке, действие каталога, честное состояние внешней среды Linux, компактная память и счётчики. Подробности устройства раскрываются отдельно. Установленная Ubuntu и другие несуществующие гости не выдуманы.
- Каталог: иллюстрации интерфейсов, официальное происхождение образов, версия, архитектура, совместимость, детали и действие скачивания. Каталог реально доступных образов Alpine сохранён. Windows 11 Evaluation скачивается внутри приложения. Windows 10 остаётся через официальный источник.
- Загрузки/коллекция: реальное состояние файлов, заполнение поверхности, пауза и продолжение, импорт, профили и журналы.
- Настройки: главная страница со списком разделов, оформление, загрузки, система, Linux, помощь, диагностика и сброс. Язык, тема, анимации, вибрация, сеть и прочие настройки сохраняются.
- Профили: простой выбор, название, движок, архитектура, профиль производительности; расширенная сохранённая конфигурация показана отдельно. Ресурсы QEMU здесь не применяются, поэтому не представлены как работающие настройки среды.
- Знакомство: четыре этапа из нового плана, карусель форм, отдельный текст, сегменты, конечное конфетти, переход к главному экрану. При выключенном движении всё доступно мгновенно.

## Шрифты, изображения и права

- Comfortaa, Unbounded, Outfit, Syne: официальные файлы из `github.com/google/fonts/tree/main/ofl/`, SIL Open Font License 1.1; копии лицензий в `docs/ui-kit/*-OFL.txt`. Comfortaa и Unbounded проверены на кириллицу средствами fontTools. Outfit использует кириллический fallback; Syne применяется только к OSify в шапке.
- Alpine Linux: официальный SVG `https://alpinelinux.org/alpinelinux-logo.svg`, преобразован в VectorDrawable с сохранением контуров; бренд принадлежит Alpine Linux, используется для идентификации. Отдельная свободная лицензия на товарный знак не предполагается.
- Превью ОС — процедурные нативные иллюстрации терминала/рабочего стола, созданные для проекта, Apache-2.0; на каждой видна подпись «Иллюстрация интерфейса». Это не официальные скриншоты и не доказательство работающего гостевого экрана. Они локальные, не требуют загрузки, декодирования и сетевого кэша.
- Знак Windows используется для идентификации продукта Microsoft. Windows ISO не включён в APK или архив проекта.
- UI Kit предоставлен пользователем; отдельной лицензии в ZIP нет. Его происхождение не приравнивается к лицензии AndroidX.

## Прямая загрузка Windows и границы проверки

Официальная ознакомительная Windows 11 Enterprise LTSC 2024 Evaluation, x86_64, English, 90 дней:

- Страница: https://www.microsoft.com/en-us/evalcenter/download-windows-11-enterprise
- Публичная ссылка страницы: https://go.microsoft.com/fwlink/?linkid=2289029&clcid=0x409&culture=en-us&country=us
- Сервер Microsoft: software-static.download.prss.microsoft.com
- Размер по заголовкам: 5 112 850 432 байта.

Проверены HEAD (HTTP 200, Accept-Ranges: bytes) и Range 32768–34815 (HTTP 206, 2048 байт, сигнатура ISO CD001). Полные 5 ГБ в среде сборки не скачивались: доступно около 1,6 ГБ. В приложении перед добавлением проверяется свободное место. Уведомления, очередь, пауза и продолжение используют существующий WorkManager.

Для этой строго закреплённой ознакомительной ссылки эталонный SHA-256 издателя не получен: приложение сохраняет локальный хеш и не называет файл проверенным по манифесту. Для Alpine обязательная проверка официального хеша сохранена. Исключение для пустого хеша ограничено точными URL, размером, архитектурой и типом Windows Evaluation. Каждый редирект проверяет HTTPS и разрешённый хост.

Получение Windows 10 через официальный API Microsoft было отклонено Sentinel. Поддержка прямой загрузки Windows 10 не заявляется. Предоставлена ссылка на официальную страницу и импорт скачанного файла. Обход защиты сервиса и сторонние переупакованные образы не использованы.

## Найденные и исправленные ошибки

- Несогласованная палитра из-за автоматически включённых цветов обоев.
- Завышенная высота нижней панели из-за системных insets; теперь собственный Reflow, системные кнопки скрываются и возвращаются свайпом.
- Слишком крупные RAM и выбор образа; удалён малополезный график памяти.
- Неинформативные символы Aa и декоративная галочка в приветствии.
- Обрезание перехода на границах прокрутки и слоёв текста; выход использует замороженную раскладку, перемещение контейнеров и размытие полного viewport на Android 12+.
- Мелкие линии вместо конфетти; заменены бумажными частицами с вращением, воздушным сопротивлением, задержками запуска и гравитацией.
- Для нового Windows ISO исправлены выбор отложенной загрузки после разрешения уведомлений и сообщения о локальном/эталонном хеше.

## Проверки и оставшиеся ограничения

Актуальные XML, лог сборки, lint, PNG и GIF: `docs/evidence/ui-0.3.0/`.

Визуально просмотрены реальные рендеры Compose в Robolectric API 34: главная, каталог, настройки, карусель и промежуточные кадры, конфетти, выход, все состояния панели загрузки, Reflow в трёх позициях, светлая и тёмная тема на ширине 360/412 dp. Тесты также проверяют основной пользовательский поток и сохранение настроек. Не заявляется испытание всех устройств, размеров шрифта, аппаратной производительности, вибрации и рабочего гостевого стола.

Эмулятор API 30 был запущен, но остановился на проверке свободного диска: `Your device does not have enough disk space to run avd`. Новый APK на реальном Android в этой сессии не запускался. Измерений FPS нет.

QEMU и встроенный гостевой экран отсутствуют. Termux остаётся экспериментальной внешней интеграцией. Поэтому морфинг запуска показывает статус запроса и не изображает успешную загрузку ОС. Каталог не заявляет запуск Ubuntu, Debian, Fedora или Arch при отсутствии соответствующего движка. Общий переход карточки в детали пока использует нативный диалог, а не SharedTransition. Интерфейс обновлён существенно, но эти ограничения не скрываются.

Итоговая сборка: 34 теста пройдены, ошибок и пропусков нет. Lint: 0 ошибок, 23 предупреждения. Debug APK подписан Android debug-ключом, подпись проверена apksigner. Дополнительно отрендерен светлый экран с русским шрифтом масштаба 1,35 и проверены видимые подписи Reflow/готовности.
