# OSify 0.4.3 — изменения и проверка

Дата: 3 ноября 2026. APK: Android 8+ (API 26), ARM64 / x86_64, versionCode 10, target API 36.

## Сделано

- Плавный вход каталога снизу с дополнительным проявлением плиток слева; анимации фильтров и непрерывное раскрытие/закрытие карточки под неподвижным OSify. Размер и положение кнопки интерполируются; описание исчезает перед изменением ширины и возвращается в конце.
- На плитке скачивание начинается сразу, цвет заполняется по реальному прогрессу. В раскрытой карточке жирный счётчик MB / GB находится внутри кнопки и появляется снизу с задержкой между символами. Пауза/продолжение, иконки и подписи анимированы. Избыточные подписи о сохранённых частичных данных убраны.
- Настоящие изображения и прозрачные логотипы ОС из интернета. Видимая высота знаков 40 dp, единый слот 48 dp. Источники, оригиналы, лицензии и скрипт подготовки находятся в исходниках.
- 36 ОС/редакций: 28 из публичного Quickget API и 8 встроенных. Добавлены Windows XP, 7, Tiny10, Tiny11; Tiny11 имеет золотую рамку и «Лучший выбор» по вашему требованию. Это оформление, не результат сравнительного тестирования. В каталоге один Alpine virt ISO.
- Исходное приветствие 0.4.1 восстановлено байт в байт. Квадратные обложки машин, компактная главная, градиент под заголовком, проверены светлая/тёмная темы и шрифт 135%.
- Настоящий встроенный QEMU: Termux/root не нужны. Нажатие «Запустить» меняет кнопку за 500 мс, запускает отдельный процесс и открывает экран гостя. Работают ввод, масштабирование, BIOS/UEFI, pause/resume и остановка через QMP. Устранён нативный сбой при выгрузке QEMU и рекурсивное обновление статуса экрана.

## Установка и ограничения

- APK весит 20,699,694 байт. SHA-256: `05fe218e3e6569f7d1c6178335298dbb3c30fa7abc04e96764084bb7e44f3fc2`.
- Подписан локальным Android Debug сертификатом SHA-256 `5a430f433d75d0d54a41647ef97bc13ee682dbcee2ee0693876e6e76071b32d9`, совпадающим с выданным здесь 0.4.2. Ключ исходного APK 0.4.1 в архиве отсутствует: обновление поверх него потребует исходный ключ либо удаления старого приложения; удаление стирает его данные и виртуальные диски. Сначала сохраните нужные файлы.
- Windows XP/7/10/Tiny10/Tiny11 используют ваш ISO через импорт/источник. Образы Windows не включены. Обычный Windows 11 может отказать в установке: TPM 2.0 не эмулируется. Полная установка Windows и совместимость всех 36 ОС не проверялись.
- Одновременно работает одна машина. Это программная эмуляция без KVM; скорость Windows на ARM не измерена. ARM32 не поддерживается. Физический ARM64-телефон не тестировался.
- Готовые библиотеки Limbo/QEMU имеют ELF-выравнивание 4 KB. Включён Android pageSizeCompat; 16 KB устройство не проверялось. Новый JNI-адаптер выровнен на 16 KB. Успешный ZIP alignment не означает, что все ELF поддерживают 16 KB напрямую.
- «Остановить» завершает машину принудительно. Для сохранения данных используйте завершение работы внутри гостя или соответствующий пункт меню машины. Диски закрытые, хранятся в OSify и удаляются с приложением.
- Исходное приветствие сохранено по вашему требованию, включая историческое упоминание Termux; актуальный Launcher использует встроенный QEMU.

## Состав исходников

Архив содержит приложение, тесты, Gradle wrapper, реальные изображения/источники, JNI, готовые нативные библиотеки, соответствующие исходники QEMU/Limbo/GLib/SDL/libffi/pixman/EDK2 и лицензии. Публичные исходники стороннего движка увеличивают размер ZIP. Локальные пути SDK, ключи подписи, сборочные кэши и гостевые ISO/диски исключены. Инструкция сборки: README.md.
