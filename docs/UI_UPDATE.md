# OSify 0.2.0 — интерфейс

## Изменения

- Голубой значок с двумя белыми стрелками вниз: Canvas внутри приложения, векторный adaptive icon, отдельная monochrome-версия для тематических значков Android и согласованный splash.
- Приветствие: небольшой знак слева сверху, пять страниц с короткими текстами, плавное появление текста. На последней странице зелёная полоса заполняется за 850 мс с CubicBezier(0.05, 0.7, 0.1, 1), затем выполняется короткий тактильный отклик и конечная анимация конфетти из боковых углов.
- «Начать» занимает всю доступную ширину с полями экрана. После нажатия элементы приветствия уходят вверх с ускорением и небольшим сдвигом по времени. На Android 12+ применяется вертикальное размытие RenderEffect. Главные блоки обзора появляются снизу по очереди с замедлением.
- При reduced motion остаются короткие затухания, при off переходы мгновенные. Системный animator scale учитывается. Тактильный отклик зависит от настройки приложения и системного разрешения тактильных эффектов.
- Обзор: крупная кнопка каталога, асимметричные тональные поверхности, блок памяти, счётчики коллекции и загрузок, плавающая округлая навигация. Счётчики открывают коллекцию, кнопка настройки в шапке работает.
- Каталог: крупный заголовок, разноцветные карточки Linux и Windows, поиск и фильтры. Коллекция, группы настроек и общие компоненты согласованы с новым оформлением. Сохранены стандартные Material-компоненты, динамическая палитра и светлая/тёмная тема.
- Убраны рекламные заголовки и декоративные разделители-точки. Обновлены русские и английские тексты приветствия, обзора, коллекции и каталога.
- Windows 10 и 11 доступны отдельными карточками в поиске и ISO-фильтре. «Скачать у Microsoft» открывает официальный сайт; после скачивания файл импортируется в коллекцию системным выбором файла. Это не автоматическая загрузка через очередь Alpine и не поддержка запуска Windows.

При заключительной проверке также исправлена гонка восстановления импорта: новый импорт теперь ждёт завершения стартовой сверки, чтобы его не приняли за прерванную работу предыдущего запуска.

## Проверки и ограничения

Результаты текущей сборки и снимки интерфейса находятся в `evidence/ui-0.2.0`. Старые результаты `TEST_RESULTS.md` и снимки вне этой папки относятся к версии 0.1.0.

UI-тесты проверяют пять страниц без анимаций, русский пропуск, полный анимированный проход с возвратом с последней страницы, поиск Windows 10/11, детали Alpine, профили и настройки. Снимки получены в Robolectric API 34. Показатели памяти в этой тестовой среде могут быть недоступны и не заменены вымышленными значениями.

Тактильный отклик, производительность размытия и внешний вид значка в конкретном лаунчере требуют проверки на телефоне. Эмуляторный smoke-test 0.1.0 не считается испытанием нового APK. Поддержка движков в этом обновлении не менялась: QEMU и встроенный гостевой рабочий стол отсутствуют, Termux остаётся экспериментальным.

Итог: 30 JVM/Robolectric-тестов пройдено (20 core + 10 app), lint: 0 errors, 20 warnings. Debug APK собран и проверен apksigner. Команда: `:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`.
