# OSify 0.3.1 — уточнения по V11

Использован приложенный пользователем `M3_Expressive_Extras_V11.html`, сохранённый в `docs/ui-kit/`. Реализация нативная, на Compose.

Изменения:

- В нижней панели снова четыре раздела: главная, каталог, загрузки, настройки. Настройки также доступны из шапки.
- Navigation Reflow соответствует последним правилам V11: активная поверхность 35/12/35/12 dp, внешняя 31 dp, крайние положения меняют только соответствующий угол на 16 dp. Ширины перераспределяются плавно. Подпись использует Comfortaa Bold вместо тонкой числовой гарнитуры; размер адаптирован для увеличенного системного шрифта.
- Новая общая раскладка AnimatedPageColumn анимирует каждый непосредственный элемент страницы, включая шапку, блок среды Linux, память, действия, каталог, файлы и настройки. Состояния данных не перезапускают анимацию; новый переход на страницу перезапускает. Вложенные страницы настроек имеют свой ключ перехода.
- Все элементы приветствия появляются вместе с подъёмом. Номера и подписи плиток также получают движение при активации.
- Приветствие использует геометрию именно `.page.active` из раздела Navigation → Page Morph: активные углы 44/16/44/16 dp, неактивные 30 dp. Цвет, форма, позиция и масштаб интерполируются. Сохранены свайпы, выглядывание следующей плитки, уменьшение и уход за экран.
- Заголовок и описание приветствия отдельно от плиток: старый текст затухает и уходит вверх, новый проявляется снизу; интервалы уменьшают наложение надписей.
- Системное отключение анимаций и настройки reduced/off сохранены.

Проверка: Robolectric API 34, реальные рендеры Compose на ширинах 360/412 dp, светлая/тёмная тема, русский шрифт 1,35. Дополнительно записаны промежуточные кадры всех четырёх страниц, возврата на главную, входа в оформление и возврата в настройки. На устройстве пользователя не испытывалось; FPS и тактильный отклик не измерялись.

Компактная сборка подписывается прежним Android debug-ключом по v1/v2/v3; подпись дополнительно проверяется для API 36 (Android 16). Это полное приложение, без разделения APK на части. Запуск ISO и QEMU в этом обновлении не добавлялись.

Итог: 35 тестов пройдено, 0 errors, 23 warnings. Логи и кадры находятся в `docs/evidence/ui-0.3.1`.
